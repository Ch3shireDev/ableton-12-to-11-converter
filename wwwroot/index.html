Convert Ableton Live 12 projects to Live 11

Ableton Live cannot normally open projects saved by a newer major version. This tool converts the XML structure inside an Ableton Live Set (.als) from Live 12 format to a format compatible with Live 11.

How the Ableton 12 to 11 converter works

  1. Select your Ableton Live 12 .als file.
  2. The file is decompressed and converted locally.
  3. Download the converted Ableton Live 11 .als file.
